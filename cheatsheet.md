# Cheatsheets

## Third Party Apps
- [rcmd](https://lowtechguys.com/rcmd/)
    - <RightCmd-Letter> -> Open app that starts with letter
- [Magnet](https://magnet.crowdcafe.com/)
    - <Ctrl-Opt-←↑→↓> -> Snap window to half of the screen in that direction
    - <Ctrl-Opt-Enter> -> Maximize window
    - <Ctrl-Opt-C> -> Center window

## Ghostty/Wezterm

All keybindings are found in Ghostty's [config](ghostty/config)

#### Tab Management
- <Cmd-t> -> New Tab
- <Ctrl-Tab> -> Cycle Next Tabs
- <Ctrl-Shift-Tab> -> Cycle Previous Tabs
- <Cmd-Number> -> Open (Number) Tab

#### Splits
- <Cmd-\> -> New Horizontal Split
- <Cmd--> -> New Vertical Split
- <Cmd-hjkl> -> Move to split
- <Cmd-←↑→↓> -> Move to split
- <Cmd-Shift-hjkl> -> Resize Split in Direction
- <Cmd-Shift-←↑→↓> -> Resize Split in Direction

#### Other
- <Ctrl-l> -> Clear screen
- <Cmd-r> -> Reload Ghosty Config
- <Cmd-w> -> Close Tab/Surface

### Fuzzy find for Fish ([fzf-fish](https://github.com/PatrickF1/fzf.fish))

- <Ctrl-Opt-f> -> Search directory
- <Ctrl-r> -> Search history
- <Ctrl-Opt-l> -> Search Git log
- <Ctrl-Opt-s> -> Search Git status
- <Ctrl-Opt-p> -> Search processes
- <Ctrl-v> -> Search variables
