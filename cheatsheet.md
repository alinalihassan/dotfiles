# Cheatsheets

## Third Party Apps
- <RightCmd-Letter> -> Open app that starts with letter([rcmd](https://lowtechguys.com/rcmd/))
- <Cmd-Tab> -> Switch between windows ([AltTab](https://alt-tab-macos.netlify.app/))
- <Ctrl-Opt-←↑→↓> -> Snap window to half of the screen in that direction ([Magnet](https://magnet.crowdcafe.com/))
- <Ctrl-Enter> -> Maximize window ([Magnet](https://magnet.crowdcafe.com/))

## Terminal

- <Ctrl-l> -> Clear screen

### Fuzzy find for Fish ([fzf-fish](https://github.com/PatrickF1/fzf.fish))

- <Ctrl-Opt-f> -> Search directory
- <Ctrl-r> -> Search history
- <Ctrl-Opt-l> -> Search Git log
- <Ctrl-Opt-s> -> Search Git status
- <Ctrl-Opt-p> -> Search processes
- <Ctrl-v> -> Search variables

## [Wezterm](https://wezfurlong.org/wezterm/)

### Panes

- <Super-\> -> New vertical pane
- <Super--> -> New horizontal pane
- <Super-hjkl> -> Change pane in that direction
- <Super-←↑→↓> -> Change pane in that direction
- <Super-Shift-hjkl> -> Grow/shrink pane in that direction
- <Super-Shift-←↑→↓> -> Grow/shrink pane in that direction

### Tabs

- <Ctrl-Tab> -> Switch to next tab
- <Ctrl-Shift-Tab> -> Switch to previous tab
- <Super-digit> -> Switch to that specific tab
- <Super-t> -> New tab
- <Super-w> -> Close current tab

### Other

- <Super-n> -> New window
- <Super-q> -> Quit all terminals
- <Super-r> -> Reload terminal
- <Super-f> -> Search current selection or empty
- <Super-Shift-f> -> Sessionizer (search for repositories and open workspace upon selection)

## NeoVim ([LunarVim](https://www.lunarvim.org/))

### Terminal

- <Opt-1> -> Toggle horizontal terminal
- <Opt-2> -> Toggle vertical terminal
- <Opt-3> -> Toggle popup terminal
